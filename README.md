# 焼酎キープ帳（試作版）

お店でキープしている焼酎を、ブラウザから手軽に管理する最小版です。

## できること

- キープ中のボトル数の表示
- ボトルの追加（登録済みの店名・銘柄の選択／新しい店名・銘柄の追加、残量、開始日、最終来店日、メモ）
- 残量スライダーと ±10% ボタンでの即時更新（変更した日を来店日へ自動追加）
- 店ごとにまとめて表示し、店名の横に最終来店からの経過日数、銘柄ごとにキープ回数を表示
- 店名を押すと、その店のキープ履歴を新しい順・通し番号つきで表示（残量0%でも店名と履歴は残る）
- 店舗ごとの来店日を月間カレンダーにマークし、過去のキープ日も来店日へ自動反映。日付の追加・編集・削除、同じ日の重複防止に対応
- 「今日来店した」で来店履歴を追加し、最終来店からの経過日数と並び順へ自動反映
- 店舗の履歴画面で現在地を一度登録し、次回からGPSで最寄りの登録済み店舗を店名欄へ選択
- 追加メニューの「ラベル画像を登録」から、銘柄ごとのボトルラベル写真を設定
- 追加メニューから、現在キープ中のボトルまたは過去のキープ履歴を登録
- 追加メニューから、ボトル・来店履歴・ラベル画像・店舗位置をまとめてバックアップ／復元
- ボトル詳細の「飲み切り＋次の銘柄を入力」で、現在の残量を0%にして、その店を選択済みの次回ボトル入力画面を表示
- 過去の履歴は店名・銘柄・キープ日だけを入力し、同じ店・同じ銘柄内で日付順に回数を自動採番
- 履歴一覧の「編集」「削除」から内容を修正・削除し、回数を自動で採番し直す
- 来店日・残量・開始日による並び替え
- ホーム画面を、位置登録済み店舗の現在地に近い順で並び替え（未登録店舗は最後に表示）
- 端末のブラウザ内への自動保存（localStorage）
- メールリンクによるSupabaseログイン
- ログイン後、端末内の店舗・ボトル・来店日・ラベル画像を、元データを残したままSupabaseへ初回移行

## 開き方

`index.html` をブラウザで開いてください。サーバーやインストールは不要です。

試作用の3本が最初に入っています。追加・変更・削除内容は同じブラウザ内に保存されます。

## スマホで使う

GitHub Pagesで公開したURLをスマホで開き、ホーム画面に追加するとアプリのように使えます。

- iPhone: Safariの共有ボタンから「ホーム画面に追加」
- Android: Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」

一度開いておけば、通信できない場所でも画面を開けます。ボトル情報は端末・ブラウザごとに保存されるため、別の端末には自動同期されません。

## Supabase接続

公開版は `supabase-config.js` の設定を使い、メールリンクでSupabaseへログインできます。別プロジェクトをローカルで試す場合は、`supabase-config.example.js` を参考に設定します。

ブラウザに公開してよいPublishable keyだけを使用し、Secret keyやデータベースのパスワードはアプリやGitHubに保存しません。ログイン後の「クラウドへの移行を開始」から、既存の端末内データを残したままSupabaseへ保存できます。途中で止まっても、再実行時は登録済みデータを確認して重複を避けます。

過去の残量変更の内訳は端末内に記録されていないため、初回移行では各ボトルの現在残量を保存します。移行後の自動同期と残量更新履歴の記録は、次の工程で追加します。
