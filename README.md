# 焼酎キープ帳（試作版）

お店でキープしている焼酎を、ブラウザから手軽に管理する最小版です。

## できること

- キープ中／期限が近いボトル数の表示
- ボトルの追加（店名、銘柄、容量、残量、開始日、期限、メモ）
- 残量スライダーと ±10% ボタンでの即時更新
- 期限・残量・開始日による並び替え
- 端末のブラウザ内への自動保存（localStorage）

## 開き方

`index.html` をブラウザで開いてください。サーバーやインストールは不要です。

試作用の3本が最初に入っています。追加・変更・削除内容は同じブラウザ内に保存されます。

## スマホで使う

GitHub Pagesで公開したURLをスマホで開き、ホーム画面に追加するとアプリのように使えます。

- iPhone: Safariの共有ボタンから「ホーム画面に追加」
- Android: Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」

一度開いておけば、通信できない場所でも画面を開けます。ボトル情報は端末・ブラウザごとに保存されるため、別の端末には自動同期されません。
