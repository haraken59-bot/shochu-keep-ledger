## 追加確認

- 残量を0%にすると対象ボトルはメインから消え、店舗名は残ることを確認。
- Service WorkerがVer.31の画面、Worker、3種類のWASM候補、日本語／縦書き日本語データをすべて取得したことをHTTPログで確認。
- サーバー停止後もVer.31が起動し、保存済みデータが残ることを確認。
- HTMLのID重複0件、JavaScriptが参照する存在しないID 0件、差分の空白エラー0件。
- 失敗項目は0件。未確認項目は主にスマートフォン実機、実GPS、認証済みSupabase、複数端末を必要とするもの。
