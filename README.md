# 焼酎キープ帳（試作版）

お店でキープしている焼酎を、ブラウザから手軽に管理する最小版です。

## できること

- キープ中のボトル数の表示
- ボトルの追加（登録済みの店名・銘柄の選択／新しい店名・銘柄の追加、残量、開始日、最終来店日、メモ）
- 残量スライダーと ±10% ボタンでの即時更新（変更した日を来店日へ自動追加）
- 店ごとにまとめて表示し、店名の横に最終来店からの経過日数、銘柄ごとにキープ回数を表示
- 店名を押すと、その店の来店クイック画面を表示。キープ履歴はクイック画面から新しい順・通し番号つきで確認可能（残量0%でも店名と履歴は残る）
- 来店クイック画面で、キープ中の複数ボトルの残量を個別に変更・保存し、今日の来店を記録
- 店舗ごとの来店日を月間カレンダーにマークし、過去のキープ日も来店日へ自動反映。日付の追加・編集・削除、同じ日の重複防止に対応
- 「今日来店した」で来店履歴を追加し、最終来店からの経過日数と並び順へ自動反映
- 店舗の履歴画面で現在地を一度登録し、次回からGPSで最寄りの登録済み店舗を店名欄へ選択
- ホームの「近くの登録店」で、1km以内の登録済み店舗を距離順に複数表示（店舗の確定は利用者が行う）
- 追加メニューの「ラベル画像を登録」から、銘柄ごとのボトルラベル写真を設定
- スマホのカメラでラベルを撮影し、端末内の無料OCRで登録済み銘柄の候補を最大3件表示。候補選択後は従来のボトル登録画面で確認して保存
- 追加メニューから、現在キープ中のボトルまたは過去のキープ履歴を登録
- 追加メニューから、ボトル・来店履歴・ラベル画像・店舗位置をまとめてバックアップ／復元
- ボトル詳細の「飲み切り＋次の銘柄を入力」で、現在の残量を0%にして、その店を選択済みの次回ボトル入力画面を表示
- 過去の履歴は店名・銘柄・キープ日だけを入力し、同じ店・同じ銘柄内で日付順に回数を自動採番
- 履歴一覧の「編集」「削除」から内容を修正・削除し、回数を自動で採番し直す
- 来店日・残量・開始日による並び替え
- ホーム画面を、位置登録済み店舗の現在地に近い順で並び替え（未登録店舗は最後に表示）
- 端末のブラウザ内への自動保存（localStorage）
- メールリンクによるSupabaseログイン
- ログイン後、端末内の店舗・ボトル・来店日・ラベル画像を、元データを残したままSupabaseへ初回移行
- 初回移行後、ボトル・来店日・店舗位置・ラベル画像の変更をSupabaseへ自動保存
- 残量変更時に、変更前後の残量と更新日をSupabaseへ履歴として保存
- 圏外や一時的な通信エラー時は端末内へ保存し、通信回復後に自動再送
- ログイン後、Supabaseに保存済みの店舗・ボトル・来店日・ラベル画像を、確認付きで新しい端末へ読み込み
- 起動・再表示・保存前にクラウドの更新を確認し、別端末の新しいデータがある場合は自動上書きを止めてホームに通知
- クラウド変更の残量・来店日・追加・削除をホームに一覧表示
- 端末側に未送信の変更がなければクラウド内容を自動反映し、両方に変更がある場合は確認まで停止
- ハラケンAI向けの参照専用RPCから、ログイン中の本人の店舗名・銘柄・残量・最終来店日・状態を取得

## 開き方

`index.html` をブラウザで開いてください。サーバーやインストールは不要です。

試作用の3本が最初に入っています。追加・変更・削除内容は同じブラウザ内に保存されます。

## スマホで使う

GitHub Pagesで公開したURLをスマホで開き、ホーム画面に追加するとアプリのように使えます。

- iPhone: Safariの共有ボタンから「ホーム画面に追加」
- Android: Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」

一度開いておけば、通信できない場所でも画面を開けます。初回移行済みの端末では変更内容をSupabaseにも自動保存します。新しい端末では同じメールアドレスでログインし、「クラウドからこの端末へ読み込む」を実行すると保存済みデータを利用できます。

ラベル文字認識にはアプリ内へ同梱したTesseract.jsと日本語学習データを使います。初回表示時に必要なファイルを端末へキャッシュするため、2回目以降は通信が不安定でも文字認識を利用できます。写真はOCR用の外部サービスへ送信されません。初回キャッシュは約25MBです。

## Supabase接続

公開版は `supabase-config.js` の設定を使い、メールリンクでSupabaseへログインできます。別プロジェクトをローカルで試す場合は、`supabase-config.example.js` を参考に設定します。

ブラウザに公開してよいPublishable keyだけを使用し、Secret keyやデータベースのパスワードはアプリやGitHubに保存しません。ログイン後の「クラウドへの移行を開始」から、既存の端末内データを残したままSupabaseへ保存できます。途中で止まっても、再実行時は登録済みデータを確認して重複を避けます。

過去の残量変更の内訳は端末内に記録されていないため、初回移行では各ボトルの現在残量を保存します。初回移行後に行った残量変更は、変更前後の残量と更新日を履歴として保存します。残量を変更した日は来店日にも追加されます。

## ハラケンAI参照連携

Ver.28では、認証済みの本人データだけを読み取る `get_shochu_keep_reference` RPCを追加します。標準では現在キープ中のボトルだけを返し、追加・変更・削除はできません。接続方法と返却項目は [`docs/HARAKEN_AI_REFERENCE.md`](docs/HARAKEN_AI_REFERENCE.md) を参照してください。
