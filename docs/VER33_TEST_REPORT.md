## Supabase

- `remaining_updates` をそのまま再利用し、新規テーブルは追加していない。
- `undo_latest_bottle_remaining` RPCを追加した。
- RPCはボトルと最新履歴をロックし、本人所有、最新履歴、現在残量、0%禁止、再取り消し禁止を検証する。
- 成功時は逆向きの `remaining_updates` を1件追加し、`bottles.current_remaining`、`status`、`last_updated_at` だけを更新する。
- `store_visits` と `bottles.last_visited_at` は変更しない。
- RPCはsecurity invokerで、実行権限はauthenticatedのみ。anonは実行不可。
- トランザクション試験後、確認用の店舗・ボトル・履歴はいずれも0件で、既存データには残していない。

## 実機未確認事項

- 認証済みスマートフォンでの通信断・復帰をまたぐ自動同期。
- 別の実端末からの履歴読込と2台同時編集の競合通知。
- 実機カメラ、GPS、OCR、Supabase Storageの往復。
